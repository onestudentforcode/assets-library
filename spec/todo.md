# MVP 范围

- [x] Next.js、TypeScript、Tailwind CSS、shadcn/ui、pnpm 全栈基础
- [x] JPEG、PNG、WebP 图片本地多选、逐文件上传和悬停预览
- [x] H.264 MP4 视频本地多选、逐文件上传和悬停预览
- [x] 类型级大小限制和明确失败原因
- [x] Chat Completions / Responses 兼容模型分析
- [x] 审核、直接入库、概览、详情、编辑、重试和删除
- [x] worker 在服务端按时长和分位点提取 1–5 张视频关键帧，千问以多图片方式分析画面
- [x] 上传视频按自然场景切分，完整大小门禁通过后将各分镜作为独立来源素材解析
- [x] 分镜批次状态、来源文件名展示、统一入库、整批回滚和失联恢复
- [x] 将固定版本的 scene-detect-service 纳入 Compose，并限制为本机访问
- [ ] 音频、URL 上传、批量编辑/删除、人工分镜编辑和通用转码（后续阶段）
